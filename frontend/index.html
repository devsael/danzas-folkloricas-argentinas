📚 Plan de Estudio

Ruta estructurada para aprender danzas folklóricas argentinas

Nivel Inicial

3-4 meses
  • ✓ Introducción a las danzas folklóricas argentinas
  • ✓ Historia y regiones de origen
  • ✓ Técnica básica y coordinación
  • ✓ Chacarera simplificada
  • ✓ Gato elemental
  • ✓ Zamba: primeros pasos
  • ✓ Palmas y ritmo básico

Nivel Intermedio

4-5 meses
  • ✓ Dominio de Chacarera completa
  • ✓ Gato con complejidad rítmica
  • ✓ Zamba romántica y expresiva
  • ✓ Introducción a Chamamé
  • ✓ Cueca básica
  • ✓ Combinación de danzas
  • ✓ Interpretación y estilo personal

Nivel Avanzado

5-6 meses
  • ✓ Dominio total de todas las danzas
  • ✓ Tango folklórico (conexión con la historia)
  • ✓ Chamamé avanzado
  • ✓ Creación de coreografías propias
  • ✓ Pedagogía de danzas folklóricas
  • ✓ Capacidad de enseñanza
  • ✓ Presentaciones públicas y eventos

💡 Nota: El tiempo de avance depende de la dedicación personal. Los talleres se adaptan al ritmo de aprendizaje de cada grupo. La práctica constante es fundamental.
